\section{Introduction}
\label{sec:intro}

We classify images into \emph{hotdog} and \emph{not hotdog}, recreating the ``SeeFood'' app from \emph{Silicon Valley}. The dataset draws on several ImageNet categories (food, frankfurter, chili-dog, pets, furniture, people). We compare CNNs trained from scratch with a pretrained ResNet18 used via transfer learning, and probe the best model with saliency maps and SmoothGrad.

\section{Background}
\label{sec:background}

CNNs learn a hierarchy of convolutional filters, from edges in early layers to object parts in deeper layers, making them well suited to image classification. Batch normalization stabilizes activation statistics across a mini-batch and eases optimization; dropout and weight decay reduce overfitting by limiting the network's tendency to memorize training examples. Transfer learning reuses a network pretrained on a large dataset (ImageNet) so that only the final classifier needs retraining, which helps when the target dataset is small. We use ResNet18, a residual architecture with skip connections, as the pretrained backbone.

\paragraph{Saliency and SmoothGrad.} For input $x$ and target-class score $s_c(x)$, the vanilla saliency map is the gradient
\begin{equation}
M(x) = \left| \partial s_c(x) / \partial x \right|,
\label{eq:saliency}
\end{equation}
which is often noisy since gradients of deep networks vary sharply between nearby points. SmoothGrad averages $M$ over $n$ noisy copies of $x$:
\begin{equation}
\hat{M}(x) = \tfrac{1}{n}\textstyle\sum_{i=1}^{n} M(x + \epsilon_i), \; \epsilon_i \sim \mathcal{N}(0, \sigma^2 I).
\label{eq:smoothgrad}
\end{equation}
Adding noise $\epsilon\sim\mathcal{N}(0,\sigma^2I)$ to $x$ is equivalent to sampling $x+\epsilon \sim \mathcal{N}(x,\sigma^2I)$ directly, so this averages saliency over samples drawn around $x$. Small $\sigma$ leaves the map noisy; large $\sigma$ blurs out real structure.

\section{Method}
\label{sec:method}

\paragraph{Data split.} To avoid train/val/test leakage, we hold out a stratified 80/20 train/validation split from the training data (class balance preserved in both parts) and use it for model selection and early stopping throughout. Crucially, the best checkpoint of each model is chosen by validation accuracy, not test accuracy: picking a model based on test performance would leak information from the held-out test set into the model-selection process and bias the reported results, which is not proper practice. The separate test set is never touched during development and is evaluated only once per model, at the very end.

\paragraph{Data augmentation.} The baseline pipeline given for the exercise only resizes images to $128\times128$ and converts them to tensors, with no augmentation or normalization. We extended this ourselves for training: random horizontal flips ($p{=}0.5$), random rotations (up to $10^\circ$), brightness/contrast/saturation jitter, and normalization (mean/std $0.5$); the test split keeps only resize, tensor conversion, and normalization, so evaluation stays deterministic. For ResNet18, the training split similarly adds random flips and rotations (no color jitter), using ImageNet normalization statistics instead. We did not run a formal ablation isolating augmentation's effect on accuracy.

\paragraph{Models.} \textbf{Basic CNN}: 3 conv layers (16/32/64 channels), ReLU, max pooling, dropout classifier. \textbf{Regularized CNN}: adds batch normalization, adaptive average pooling, dropout ($p{=}0.5$), weight decay, early stopping. \textbf{Deeper CNN}: regularized architecture plus a fourth conv block (128 channels). \textbf{ResNet18 transfer learning}: images resized to $224\times224$; an ImageNet-pretrained ResNet18 with the backbone frozen and the final layer replaced by dropout + a 2-class linear layer, with only this head trained.

\paragraph{Training.} All models use cross-entropy loss and Adam (lr $=0.001$); the regularized CNN adds weight decay $10^{-4}$ and early stopping (patience 3). Stratified 5-fold cross-validation on the training set further checks the stability of the ResNet18 result. For saliency, we use the gradient of the \emph{hotdog} class score (Eq.~\ref{eq:saliency}) on 5 hotdog test images, and SmoothGrad (Eq.~\ref{eq:smoothgrad}) with $n{=}25$, $\sigma{=}0.15$; both are reduced to a heatmap via the max absolute gradient across color channels.

\subsection{Misclassified Test Images}
\label{sec:misclassified}

Running the ResNet18 model over the full test set, 155 of 1862 images (8.3\%) are misclassified, consistent with the 91.68\% test accuracy in Table~\ref{tab:results}.

\begin{figure}[h]
\centering
\includegraphics[width=\linewidth]{misclassified.jpg}
\caption{Four false negatives, true \emph{hotdog} predicted \emph{nothotdog} (top), and four false positives, true \emph{nothotdog} predicted \emph{hotdog} (bottom).}
\label{fig:misclassified}
\end{figure}
\FloatBarrier

Fig.~\ref{fig:misclassified} shows both error directions. The false negatives (top row) are all heavily dressed hotdogs, such as chili dogs, cheese dogs, and a tray of hotdogs half-hidden in their buns, where toppings obscure the plain bun-and-sausage silhouette. Confidence is mostly low (51--53\%, near a coin flip), except one chili-cheese dog at 91\%, where the sausage is barely visible under cheese and beans. The false positives (bottom row) show the opposite failure: foods with an elongated, bread- or wrapper-enclosed shape are mistaken for hotdogs with very high confidence, namely spring rolls at 98.9\% and a prosciutto sandwich at 97.0\%, while a charcuterie platter (51.7\%) and a pasta dish (56.2\%) are much weaker, near-coin-flip errors with no obvious shape cue. Together this suggests the model relies heavily on the elongated hotdog silhouette: dressed hotdogs that hide this shape are missed, while other foods that happen to share it are confidently mistaken for hotdogs, an obvious and interpretable failure mode in both directions.

\subsection{Saliency Maps and SmoothGrad}
\label{sec:saliency-results}

\begin{figure*}[t]
\centering
\includegraphics[width=0.85\textwidth]{salency_smoothgrad.jpg}
\caption{Five hotdog test images (top), vanilla saliency (middle), and SmoothGrad, $\sigma=0.15$ (bottom).}
\label{fig:saliency}
\end{figure*}
\FloatBarrier

Do the saliency maps (Fig.~\ref{fig:saliency}) make sense? Only partially: vanilla saliency is dominated by speckled noise across the whole image. SmoothGrad is somewhat cleaner and, for two of the five images, shows a faint bright region near the hotdog/mouth, but the improvement is marginal overall and no map gives a crisp hotdog outline. A likely cause is that the gradient passes through the deep, frozen, piecewise-linear ResNet18 backbone, which is known to produce noisy raw gradients; a larger sample count or a $\sigma$ sweep (not explored here due to time) would likely help.

\subsection{Limitations}

Beyond the eight examples in Fig.~\ref{fig:misclassified}, we have not systematically checked whether the same shape-based pattern holds across all 155 misclassified images.

\section{Conclusion}
\label{sec:conclusion}

Transfer learning with ResNet18 was the best approach, reaching 91.68\% test accuracy (5-fold CV: $93.99\%\pm1.18$pp), well above any CNN trained from scratch. Saliency/SmoothGrad maps give only a weak signal that the model attends to the hotdog region, suggesting noisy gradients through the frozen backbone. It can seem like a lot of the false positive misclassifications happens when there is a food related image being predicted, so maybe the dataset should contain more images of food in order for the model to become even more robust.
